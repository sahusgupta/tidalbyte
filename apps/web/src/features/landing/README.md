# EarthLab landing

The root (`#/`) is a scroll-driven introduction inspired by the supplied reference recording: an illustrative input diagram, Earth, then Houston aerial imagery. `#/simulate` opens a five-area chooser before entering the flood simulation. Legacy `#/atlas` links resolve to the same chooser; the old Atlas screen has been removed. `#/earth` now resolves to the scrolling landing page. Existing `#/zone/<id>` links remain available; the simulation header has a Houston-area selector. Home always returns to the scrolling landing page. The single Open EarthLab button sits beneath the final Houston description and opens the area chooser. A keyboard skip link also opens the chooser.

This extends the existing Source Sans 3/Baskervville typography with the requested subtle blue-gray surfaces and blue accents. No new raster assets or external API keys are needed. Cesium uses the existing imagery helpers and credits. The landing descent additionally streams Esri World Imagery tiles, with provider attribution, so intermediate zoom levels do not magnify the low-resolution Natural Earth overview. Tiles are display-only and are not downloaded into the repository. Network failure falls back to the bundled globe; Houston archive and detail layers stay above the world imagery. The camera follows native scrolling with eased interpolation; reduced-motion removes interpolation. Imagery failure leaves navigation available and initialization failure uses the bundled Houston image.
